# Supuestos y restricciones del proyecto

## Alcance
Este repositorio es un ejercicio de portafolio orientado a demostrar habilidades técnicas. No está diseñado como sistema productivo final.

## Licencias y herramientas
El proyecto se construye bajo el supuesto de **no disponer de licencias empresariales**.
Por ello, el stack propuesto usa herramientas abiertas y ejecución local.

## Manejo de datos
- Los raw CSV van en `data/raw/` de forma local.
- Los outputs intermedios y featuresets también se mantienen locales.
- El repo solo versiona código, documentación y artefactos pequeños/sintéticos.

## Testing y mantenibilidad
La mantenibilidad es parte explícita del proyecto. Por ello se incluyen:
- pruebas unitarias
- pruebas de integración
- fixtures sintéticos
- estrategia de validación de datos
- estructura para futuras regresiones
